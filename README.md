# QuizzizSam

PWA de ruleta de preguntas aleatorias por dificultad (Fácil, Muy Fácil, Regalado).

## 🎮 Cómo funciona

- Pulsa **Nueva Pregunta** y la ruleta gira 5 segundos, frenando poco a poco.
- Se selecciona una card aleatoria con su dificultad.
- Haz click en la card para ver la imagen en pantalla completa.
- Botón **X** (o Esc) para cerrar.

## 📱 PWA

Se puede **instalar** en el móvil/escritorio (Añadir a pantalla de inicio) y funciona offline gracias al Service Worker.
